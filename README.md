# Omnichannel Platform

La **plateforme omnicanal** est un projet conçu pour gérer les services clients, les interactions et les canaux de communication à travers différents services. Cette plateforme utilise une architecture de microservices avec des outils modernes comme Spring Boot, Spring Cloud, et Docker.

## Description
La plateforme omnicanal permet de centraliser la gestion des interactions entre les clients et les services via différents canaux (Web, Mobile, etc.). Elle offre une gestion des utilisateurs, des clients, des notifications et des analyses en temps réel.

Le projet est conçu en utilisant une architecture microservices pour faciliter l'évolutivité et la maintenance.
